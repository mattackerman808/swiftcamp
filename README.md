# Swiftcamp

A native macOS and iOS reimagining of Garmin BaseCamp, for planning, sharing and
managing GPS routes, tracks and waypoints. Focused on motorcycle and auto
touring: plan a road route, export GPX, load it on a navigator.

Early. The map renders on both platforms; the data model and GPX support do not
exist yet.

## Architecture

Map and routing data behave differently, and most decisions follow from that.

| | Map tiles | Routing tiles |
| --- | --- | --- |
| Format | PMTiles | Valhalla graph |
| Streams over HTTP? | Yes, range requests | No, needs local disk |
| Forces a download? | No | Yes |

The map streams from a single `.pmtiles` archive; routing runs on-device via
Valhalla, so road snapping needs a per-region download. There is no backend —
static object storage and a manifest.

`docs/data-architecture.md` has the detail, including measured build sizes.

### Two renderers, one map

MapLibre Native ships iOS-only slices, so macOS renders through MapLibre GL JS
in a `WKWebView` instead. The split is confined to `MapContainer`; both
platforms consume the same `MapStyle` and the same archive.

## Build

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
and is gitignored, so regenerate after pulling.

The bundled basemap is not in git. Fetch it once after cloning; it is a ~43 MB
extract cut from the Protomaps planet in about a second.

```bash
brew install pmtiles xcodegen
./scripts/fetch-basemap.sh
xcodegen generate

xcodebuild -project Swiftcamp.xcodeproj -scheme Swiftcamp-iOS \
  -destination 'generic/platform=iOS Simulator' build CODE_SIGNING_ALLOWED=NO

xcodebuild -project Swiftcamp.xcodeproj -scheme Swiftcamp-macOS \
  -destination 'platform=macOS' build CODE_SIGNING_ALLOWED=NO
```

The macOS app takes `-SwiftcampSnapshot <path>` to write a PNG of the map once
it settles, which works without Screen Recording permission.

## Data

Map data is from [Protomaps](https://protomaps.com) daily planet builds; routing
input is [Geofabrik](https://download.geofabrik.de) extracts. Both derive from
OpenStreetMap and are ODbL, so attribution is required and it must stay visible
in the app.
